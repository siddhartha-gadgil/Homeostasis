Part 0

Homeostasis

Keeping an output fixed while everything else varies.

The phenomenon

Robust outputs in biochemistry

Cells hold some concentrations almost constant despite large changes in protein amounts, temperature or external signals.

  • EnvZ–OmpR (E. coli osmoregulation): the level of phosphorylated OmpR barely depends on the total amounts of EnvZ and OmpR (Batchelor–Goulian 2003).
  • IDHKP–IDH (glyoxylate bypass): the active IDH level is robust to enzyme levels.
  • Integral feedback: an output returns exactly to its set-point after a disturbance (bacterial chemotaxis; synthetic antithetic controllers).
Goal: make the notions precise, prove the classic results for all parameter values, and check every step in Lean.

Several distinct notions

ACR: every positive steady state has the same value of a species (Shinar–Feinberg).

Perfect adaptation: the output at equilibrium does not depend on an input.

Infinitesimal homeostasis: the derivative of the output with respect to the input vanishes (Golubitsky–Stewart).

Stochastic: what survives at low copy numbers?

In Lean these are separate predicates, linked only by proved implications.

Mass-action kinetics

Reaction networks and their ODEs

A network has species, complexes (formal sums of species) and reactions $y \to y'$ between complexes. Under mass action, each reaction fires at rate $\kappa\, x^{y}$:

$$\dot x \;=\; f_\kappa(x) \;=\; \sum_{y \to y'} \kappa_{y\to y'}\, x^{y}\,(y' - y).$$

Trajectories stay in a compatibility class $x_0 + S$, $S = \operatorname{span}\{y' - y\}$: conservation laws fix the totals.

Deficiency $\delta = n - \ell - s$: complexes, minus linkage classes, minus the rank of $S$.

structure ReactionNetwork (ι C R : Type*) where
  complex : C → ι → ℕ
  complex_injective : Function.Injective complex
  src : R → C
  tgt : R → C
  src_ne_tgt : ∀ r, src r ≠ tgt r
  complex_used : ∀ c, ∃ r, src r = c ∨ tgt r = c

def massActionField (k : R → ℝ) (x : ι → ℝ) : ι → ℝ :=
  ∑ r, N.rate k x r • N.reactionVector r

def IsPosSteadyState (k : R → ℝ) (x : ι → ℝ) : Prop :=
  IsPos x ∧ N.massActionField k x = 0

def deficiency : ℤ := (Nat.card C : ℤ) - N.numLinkageClasses - N.rank

Definitions

Absolute concentration robustness, made honest

ACR in species $s$: all positive steady states agree in $x_s$. Two traps:

Vacuous

With no positive steady state, ACR holds for every species (abNet_hasACR_vacuous).

Trivial

With a unique positive steady state, ACR holds for every species (bdNet_hasACRNonvacuous).

So headline claims use nontrivial ACR: two distinct positive steady states exist, and all share the value.

def HasACR (k : R → ℝ) (s : ι) : Prop :=
  ∀ x x', N.IsPosSteadyState k x → N.IsPosSteadyState k x' → x s = x' s

def HasACRNonvacuous (k : R → ℝ) (s : ι) : Prop :=
  (∃ x, N.IsPosSteadyState k x) ∧ N.HasACR k s

def HasACRNontrivial (k : R → ℝ) (s : ι) : Prop :=
  N.HasACRNonvacuous k s ∧
    ∃ x x', N.IsPosSteadyState k x ∧ N.IsPosSteadyState k x' ∧ x ≠ x'

The theorem being illustrated

Deficiency one and two nonterminal complexes

Shinar–Feinberg (2010). Consider a mass-action system with a deficiency-one network that admits a positive steady state. If, in the network, there are two nonterminal complexes that differ only in species $S$, then the system has absolute concentration robustness in $S$.

EnvZ–OmpR, ATP (Fig. 2B)

9 complexes, $\ell = 3$, $s = 5$, $\delta = 1$. Nonterminal pair $XT + Yp$, $XT$: ACR in $Yp$.

EnvZ–OmpR, ADP (Fig. 2D)

10 complexes, $\ell = 3$, $s = 6$, $\delta = 1$. Pair $\text{EnvZ-D} + \text{OmpR-P}$, $\text{EnvZ-D}$.

IDHKP–IDH (Fig. 3)

6 complexes, $\ell = 2$, $s = 3$, $\delta = 1$. Pair $EIp + I$, $EIp$: ACR in $I$.

We do not (yet) formalize the general theorem. Each network gets its own certificate, and all the numbers above (deficiency, linkage classes, rank) are computed in Lean.

Certificates

ACR from one polynomial identity

If for all $x$

$$x^{a}\,(x_s - c) \;=\; \sum_i g_i(x)\, f_i(x)$$

then at any positive steady state ($f = 0$, $x > 0$) we get $x_s = c$. The cofactors $g_i$ are found by an untrusted oracle (sympy, symbolic in the rate constants) and checked by Lean.

Part 2

Stability

A steady state no trajectory approaches is no explanation of robustness. Stability is a separate contract, proved separately.

Linearization

From a Hurwitz Jacobian to exponential stability

  • Lyapunov certificate: $P \succ 0$ and $J^\top P + PJ \prec 0$ give local exponential stability of $\dot x = F(x)$ when $F$ is differentiable at $x^\star$.
  • Converse Lyapunov: if $J$ is Hurwitz, such a $P$ exists ($P = \int_0^\infty e^{tJ^\top} e^{tJ}\,dt$), so a Hurwitz Jacobian suffices.
  • Certificates: exact $LDL^\top$ factorizations over $\mathbb{Q}$; Routh–Hurwitz for $3\times 3$ matrices, symbolic in the parameters.
theorem ReactionNetwork.locallyExpStable_of_isHurwitz
    (N : ReactionNetwork ι C R) {k : R → ℝ} {xs : ι → ℝ}
    (hxs : N.massActionField k xs = 0)
    (hJ : IsHurwitz (N.massActionJacobian k xs)) :
    ∃ δ > 0, ∃ c > 0, ∃ C > 0, ∀ (x : ℝ → ι → ℝ) (T : ℝ),
      N.MassActionTrajectoryOn k x T → ‖x 0 - xs‖ < δ →
        ∀ t ∈ Ico 0 T,
          ‖x t - xs‖ ^ 2 ≤ C * Real.exp (-c * t) * ‖x 0 - xs‖ ^ 2

Conservation laws

Stability within a compatibility class

With conservation laws the Jacobian is singular, so no full-space Lyapunov function exists (isoNet_no_lyapunov). Instead, choose coordinates $B$, $C$ on $S$ ($CB = I$) and ask that the restricted Jacobian $CJB$ be Hurwitz.

EnvZ–OmpR at unit rates, both models: integer restricted Jacobians ($6\times 6$, $5\times 5$), integer Lyapunov matrices, exact $LDL^\top$ factors (envz_classStable_unit, atp_classStable_unit). Both models, every unit-rate steady state, by $5\times 5$ and $6\times 6$ Routh–Hurwitz; general rates are open (Q-11).

IDHKP–IDH is stable within its classes

Rank 3, so the restricted Jacobian is $3\times 3$, explicit at every state:

$$CJB = \begin{pmatrix} -\kappa_1(x_0{+}x_1) - \kappa_2 & \kappa_1 x_1 + \kappa_2 & \kappa_2 - \kappa_6\\ \kappa_3 & -\kappa_3 & -\kappa_3 - \kappa_6 \\ \kappa_4 x_3 & \kappa_4(x_2 - x_3) & -\kappa_4(x_2{+}x_3) - \kappa_5 - \kappa_6\end{pmatrix}$$
  • $\operatorname{tr} < 0$ at every positive state.
  • $\det = -D < 0$, $D$ a positive polynomial: uses only the ACR relation $\kappa_4\kappa_6 x_I = \kappa_3(\kappa_5+\kappa_6)$.

Certificate format 8

Routh–Hurwitz for $5\times5$ and $6\times6$, by an energy identity

For $b_1,\dots,b_5 > 0$ the tridiagonal Schwarz matrix

$$S = \begin{pmatrix} 0&1&&&\\ -b_5&0&1&&\\ &-b_4&0&1&\\ &&-b_3&0&1\\ &&&-b_2&-b_1\end{pmatrix}$$ $$P = \operatorname{diag}(b_2b_3b_4b_5,\ b_2b_3b_4,\ b_2b_3,\ b_2,\ 1)$$

satisfies $PS + S^\top P = \operatorname{diag}(0,0,0,0,-2b_1)$. For an eigenvector $v$ with eigenvalue $z$:

$$\operatorname{Re} z\cdot \textstyle\sum_i p_i |v_i|^2 = -b_1 |v_5|^2,$$

so $\operatorname{Re} z \le 0$, and $\operatorname{Re} z = 0$ forces $v_5 = 0$, then $v = 0$ by the recursion. No continuity or root counting.

Positive Hurwitz quantities $a_1, a_5, \Delta_2, \Delta_3, D_4$ give positive $b_i$ with the same characteristic polynomial.

Perfect adaptation

The antithetic integral feedback motif: an output that returns exactly to its set-point, whatever the disturbance.

Antithetic integral feedback

Robust perfect adaptation, with stability

∅ →(μ) Z₁    X →(θ) X + Z₂    Z₁ + Z₂ →(η) ∅
Z₁ →(a) Z₁ + X    X →(γ) ∅   (γ: the disturbance)

$\dot z_1 - \dot z_2 = \mu - \theta x$: an integrator. At every positive equilibrium $x = \mu/\theta$, for every $\gamma > 0$; Routh–Hurwitz proves linear stability for all parameters.

Infinitesimal homeostasis

The determinant formula

Golubitsky–Stewart: input $I$ enters node $\iota$, output node $o$, branch of equilibria $X(I)$. Then

$$X_o'(I_0)\,\det J \;=\; -f_{\iota,I}\;\operatorname{adj}(J)_{o\iota} \;=\; \pm f_{\iota,I}\,\det H$$

where the homeostasis matrix $H$ is $J$ with row $\iota$ and column $o$ deleted. So the output is infinitesimally homeostatic iff $\det H = 0$.

theorem det_smul_eq_adjugate_mulVec (J : Matrix ι ι ℝ) {u v : ι → ℝ}
    (h : J *ᵥ u = v) : J.det • u = J.adjugate *ᵥ v

theorem massAction_infinitesimalHomeostasis_iff_det
    (N : ReactionNetwork (Fin (n + 1)) C R) {kfam : ℝ → R → ℝ}

    (hX : HasDerivAt X X' I₀)
    (heq : ∀ᶠ I in 𝓝 I₀, N.massActionFamily kfam I (X I) = 0)
    (hin : inputDeriv L = Pi.single i c) (hc : c ≠ 0)
